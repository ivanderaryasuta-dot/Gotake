WHERE TO PUT YOUR IMAGES
========================
Every image spot in the website is BLANK until you add a file here.
Just copy the file into this folder with the EXACT name below.
No code changes needed. Allowed types: .png .jpg .jpeg .webp .svg .gif

FILE NAME              WHERE IT APPEARS
---------------------  ------------------------------------------------------
logo.png               Blue top bar on every page + splash screen
                       (the "GT GO-TAKE" logo). Admin > Settings can also
                       upload it for you.
auth-banner.png        Left side of Login / Register / Forgot-password pages
                       (the "Just Borrow, Go Take" shopping-cart picture)

items/<ITEM CODE>.png  Photo of each item in the catalog + borrow request page.
                       Use the item's CODE from the database / Manage Items.
                       Examples:   items/PRJ-01.png
                                   items/CHR-01.png
                       (Only letters, numbers, - and _ are used. Other
                       characters in a code are ignored when looking for the file.)

TIP: if an image does not show, check (1) the exact spelling/capital letters
of the file name and (2) that it is inside assets/img/ (or assets/img/items/).
